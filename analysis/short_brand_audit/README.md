# 短英文品牌配對研究

本次是唯讀研究及記憶體內修正實驗。正式 `brandtag/`、`curated_aliases.csv`、`brand_rules.db`、`review/` 與 `output/` 均未由本次研究修改。重現入口為上層 `short_brand_audit.py`、`short_brand_proposal.py`，亦可用 `研究重現.ipynb`。

## 先說結論

GB 綠鐘與 HH 草本新淨界不是必須新增品牌庫的案例。庫內已有 `GREEN BELL [1124530]` 與 `Herb & Health [1111148]`，有比裸縮寫更明確的品牌身份支持。兩個來源字串合計 291 件商品。

但 HH 官方也使用 H&H：不能只看字面就宣告 `H&H [1120001]` 是另一品牌。建議使用完整英文名稱的 ID，並請品牌庫維護者確認舊 ID 是否應合併。現有品牌庫只有名稱、類目和業績，沒有商標權人或該 ID 的商品明細，這個限制也適用於其他短名 ID 的身份判讀。

## 數量與口徑

查詢來源為 `brand_rules.db.item_results` 的 momo 存檔，共 545,572 件不同品號、22 類別；搭配 `brand_pool.csv` 的 76,675 個品牌 ID、`brand_aliases`。本次讀取時 22 類別均已完成 14:56–15:02 的一輪輸出，已不同於上一輪對話中只更新 8 類別的時間點。這是輸出時間，不能當作原始商品的採集時間。

篩查條件：來源品牌欄（空白時取標題第一個【】）同時有中文及 1–3 字元英數；存檔結果配到英數相同、中文不相同的品牌；沒有 full/中文 human 或 curated 別名支持。品牌字串以 normalize 後的值去重，商品以品號計數；沒有把 SKU 重複計算。

| 範圍 | 品牌字串 | 品號 |
|---|---:|---:|
| 兩字元英數風險 | 28 | 899 |
| 三字元英數風險，額外 | 61 | 2,088 |
| 合計風險 | 89 | 2,987 |

風險分布於 20 類別，佔全站 0.55%。其中 1,954 件原信心 ≥90；2,522 件有自動學習別名。這些數字都是「可能缺乏獨立身份證據」的篩查，不是錯誤率，也不是宣稱 2,987 件全部錯配。MSI 微星、WD 威騰、LG 樂金等也會落入此篩查。中文省略公司後綴、產地詞或集團詞也可能合法。

本次沒有把純英文短品牌、只有中文的衍生別名、四字元以上英文碰撞全面納入，所以也不能把 2,987 當成全站所有品牌誤配的上限。

## 已重現的成因

1. `index.py` 把名稱去大小寫、標點。GB/gb、HH/H&H、GP/G.P 會共用英數索引。這可以找候選，但不足以證明同一品牌。
2. `same_entity()` 把「英文相同、另一邊沒有中文」當作同一實體；`engine.resolve_candidates()` 隨後在這群候選中取最高 ADG。H&R 安室家即使完整名稱 100 分，也會輸給只有 85 分但 ADG 更高的 H&R。
3. `pipeline._learn_auto_aliases()` 只看最終信心 ≥90 等条件，可能把這類縮寫配對的中文學入別名。資料庫實際有：綠鐘→4405709、草本新淨界→1120001、熊野→1094859，來源均為 auto。
4. 下次 `match()` 的英文、中文命中同一 ID，就會經 `both` 取得 100 的命中強度。中文其實是前次猜出的別名，卻被當作新證據。既有 FJ 修正只降低 `via=lat` 候選，擋不住已升成 `via=full` 的情況。
5. `curated` 與 `auto` 目前在索引中未形成足以解決衝突的優先關係。只加正確別名，舊的 auto 仍可勝出。

## 修正實驗

直接用現有 BrandIndex/tag，在記憶體比較三種情境。這裡標題空白、類目檢查關閉，分數不能直接當成正式各品號的分數。

| 案例 | 只加有來源支持的對照 | 另隔離衝突 auto |
|---|---|---|
| GB 綠鐘 | 仍選 gb，45 分 | 選 GREEN BELL，98 分 |
| HH 草本新淨界 | 仍選 H&H，45 分 | 選 Herb & Health，98 分 |
| JS 婕洛妮絲 | 選 jealousness，98 分 | 相同 |
| GP 超霸 | 選 GP Batteries，98 分 | 相同 |
| KUM 熊野 | 仍選 KUM，45 分 | 選 Kumano 熊野油脂，但仍因競爭只有 45 分 |
| H&R 安室家 | 仍選 H&R | 仍選 H&R，需要改候選選擇順序 |

另做了限定研究原型：有來源支持的完整字串對照優先；完整雙語自然命中優先於短名；未核實的風險字串保留候選並把信心限制於 74。6 組可選到提案 ID，3M、LG、HP、DHC、VT、SK2、FJ 豐傑生醫、BVLGARI 寶格麗、MUJI 無印良品的 9 個對照案例 ID 不變。

限制：這是限定原型，不是正式引擎的全站回歸或正確率驗證。完整名稱優先的原型也改變了其餘 7 組、54 件的候選選擇，已在對照明細列出並維持待審，未當作已確認修正。風險清單中的 MSI/WD/LG 等也會受保守待審門檻影響，不能宣稱完全沒有誤傷。

## 建議實作順序

1. **補有來源的完整品牌對照**：GB 綠鐘→GREEN BELL、HH 草本新淨界→Herb & Health 等。只限定完整字串／已查證中文名稱，不全域綁定裸 GB、HH、GP、JS、KUM。
2. **隔離衝突自動別名，保留紀錄**：先處理上述 3 筆；HH 那筆是與標準 ID 選擇衝突，不宣稱品牌身份一定錯。正式機制應可停用、記錄來源及原因、回溯，不靠靜默刪除。
3. **先做身份確認，再用 ADG 選重複 ID**：完整名稱、人工或有證據 curated 對照應先決定實體；同縮寫或同正規化字串不能獨自證明同品牌。類目衝突只能當輔助，不做一律排除。
4. **阻止自動別名自我加分**：保留命中證據來源，auto 中文不能和原本的短英文當成兩份獨立證據；只有短英數相同時不自動學中文別名。human/curated/auto 衝突需有明確處理。
5. **無法查證的保留候選待審**：不一律判 No brand 或品牌庫缺少；可先限定两字元風險，再逐步處理三字元，避免一次把大量已知正確縮寫送回人工。正確品牌的證據對照應先補上。
6. 完成修正後重跑同一快照全部類別，核對品號差異、待審增加量、純英文短品牌及中文別名；不要把記憶體實驗的分數稱為實測準確率。

不建議把英文前綴比對全面打開，也不建議只提高類目扣分：兩者都無法解決「同縮寫不等於同實體」的根因。
